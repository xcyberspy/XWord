<h2>🧐 Features</h2>

Here're some of the project's best features:

*   8 case conversion modes with live preview samples
*   Live text statistics — characters words lines and sentences
*   Dark / Light theme with localStorage persistence
*   Keyboard shortcuts (Alt+1–8) for instant case switching
*   Clipboard integration — paste from and copy to clipboard
*   Download converted text as .txt
*   Minimal SaaS-style UI — responsive mobile-friendly
